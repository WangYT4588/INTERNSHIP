# 操作指南 (USER_GUIDE)

## 1. 產表流程

| 步驟 | 動作 | 備註 |
|---|---|---|
| 1 | 讀取參考表(Excel)範圍 | 選 `data/Idq (Trq, Flux).xlsx`，自動填表軸範圍，勿手改 |
| 2 | 選擇訓練資料 (CSV) | 用含 TORQUE 欄的完整台架報告檔（格式見 REFERENCE 第 1 節） |
| 3 | 設定訓練參數 | Epochs 2000-3000、LR 0.002-0.0025、Batch 256（自動夾為全批次） |
| 4 | 執行AI分析 | 約 1-3 分鐘，狀態列顯示 1/3 -> 2/3 -> 3/3 |
| 5 | 檢查報告與圖表 | 對照下方驗收標準 |
| 6 | 匯出 Excel | 檔案被 Excel 開著會匯出失敗，先關閉 |

馬達參數頁只有 p（極對數）與 Imax 影響產表，其餘欄位只寫進匯出 metadata；
電感表載不載入都不影響結果。

## 2. 驗收標準（跑完必看）

| 指標 | 正常範圍 | 異常時檢查 |
|---|---|---|
| Id 誤差平均 | 3-5 A | 欄位是否抓對、參考表是否已載入 |
| Id 誤差最大 | 40-65 A，且在高扭矩包絡角點 | 若出現在一般工作區，檢查資料品質 |
| Iq 誤差 平均/最大 | 約 1 A / 25 A 內 | 同上 |
| T=0 高速列 Id | -80 到 -110 A（弱磁） | 接近 0 代表缺高速空載數據 |

## 3. 圖表判讀（一句話版）

- 訓練趨勢頁 loss 曲線: 綠線（驗證）平穩下降後持平 = 收斂；綠灰貼近 = 無過擬合。
- RMSE 長條: 驗證柱接近訓練柱 = 健康；高出 2 倍以上 = 過擬合。
- 散佈圖: 上排是模型、下排是最終查表，點貼近 45 度線越準。
- 結果頁曲面: 應平滑單調；低磁通高扭矩角落的平台是能力延續，正常。
- 誤差分布圖（熱力圖）: 紅色格 = 誤差大的區域，台架驗證優先掃這些點。

## 4. 誤差分析頁

載入新舊兩份台架報告（需含 torq error 欄），按誤差分析，比較兩張熱力圖。
新表整體應比舊表淡（誤差小），重點看高扭矩列。

## 5. 台架迭代（每輪更準）

1. 新表上台架跑效率圖，取得新報告 CSV（含 TORQUE）。
2. 誤差分析頁比對新舊表。
3. 新報告串接進訓練 CSV（同工作點條件不同時刪舊留新，勿平均），重新執行AI分析。
4. 補測建議: 誤差熱力圖紅區（多在 T=180-300、4500-8500 rpm）以 10 Nm / 250 rpm
   間距加掃 30-50 點，角點誤差可再減半。

## 6. 疑難排解

| 症狀 | 解法 |
|---|---|
| 找不到 Speed/Torque/Id/Iq 欄位 | 欄名不符偵測規則，見 REFERENCE 第 1 節 |
| 找不到磁通命令欄位 (Flux) | CSV 缺 Flux 欄，或有其他 flux 字樣欄位排在它前面 |
| 無法寫入檔案 | 匯出目標正被 Excel 開啟，關閉重試 |
| Unrecognized 'motor' 或 'plot_scatter_fit' | 私有屬性或 helper 被誤刪，見 REFERENCE 第 4 節補回 |
| 散佈圖水平點列 / 曲面鋸齒 | 能力包絡演算法被改壞，t_cap 必須用 cummax 版 |
| 熱力圖 Y 軸密密麻麻 | 扭矩未分箱，需 round(T/20)*20 |
| 結果與上次不同 | 檢查資料與參數；相同輸入下 rng(1) 保證結果完全重現 |
