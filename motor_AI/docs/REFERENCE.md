# 技術參考 (REFERENCE)

## 1. 資料格式

### 訓練 CSV（建議直接用完整台架報告檔）

| 欄位 | 必要性 | 說明 |
|---|---|---|
| T_dem_E | 必要 | 扭矩命令 (Nm) |
| SPEED | 必要 | 轉速 (rpm) |
| Flux | 必要 | 控制器磁通命令 (Wb)，即查表座標；勿與物理磁鏈混淆 |
| daxisCurrFbk / qaxisCurrFbk | 必要 | 電流回授 (A)，自動優先選 Fbk 欄 |
| TORQUE | 強烈建議 | 動力計實測扭矩 (Nm)，存在時取代命令值當扭矩標籤 |
| torq error | 選用 | 誤差分析頁使用（舊檔拼字 torqe error 也支援） |

自動清理: 剔除 NaN、扭矩<0、電流量 >1.1x Imax 的列；重複 (扭矩, Flux) 點取平均。
注意: V1 格式（第 2 列是單位列）只有誤差分析頁支援，當訓練資料前請先刪單位列。

### 參考表 Idq (Trq, Flux).xlsx
兩分頁（名稱含 Id / Iq）。第 1 列第 2 欄起 = 磁通軸（27 點，0-0.2065 Wb）；
第 1 欄第 2 列起 = 扭矩軸（31 點，0-300 Nm）；其餘為電流矩陣。

### 輸出 LUT（Id_Table / Iq_Table 兩分頁）
列 1-5 metadata；列 6 = 磁通軸（遞減）；欄 A 列 7 起 = 扭矩軸；B7 起 = 電流矩陣 (A)。
語意: 表[T, Flux] = 實際產生扭矩 T 所需的電流。
保證: Id<=0、Iq>=0、T=0 列 Iq=0、電流量 <=Imax、雙向單調、能力外格子 = 能力上限電流。

## 2. 演算法流程（對應程式碼 11 個區塊）

1. 讀 CSV + 欄位偵測，TORQUE 存在時重標定扭矩標籤
2. 清理與重複點平均
3. 訓練 NN: 輸入 (扭矩, Flux) 2 維，FC64-FC32-FC2，z-score，adam，rng(1) 固定可重現
4. 在參考表網格上求值
5. 計算每個扭矩列的實驗磁通涵蓋範圍 (in_support)
6. 範圍外填補: 參考表值 + 接縫偏移（差值修正，保持連續）
7. 表格校準: 最小平方微調節點，使雙線性查表最貼實測（lambda=0.5，2 輪）
8. 物理約束: 符號 -> T=0 列 Iq 歸零 -> PAVA 單調化 -> Imax 限幅（每輪校準後重套）
9. 能力包絡: t_cap = cummax(低於該磁通已達成的最大扭矩)，超出列複製能力上限電流
10. 驗證: 全部實測點查表比對，統計平均/RMS/最大誤差
11. 匯出 Excel

## 3. 三個設計決策（為什麼這樣做）

1. 表軸 = 控制器磁通命令: 物理磁鏈量值對 Id 非單調（會摺疊），v1.3 用它當軸
   導致 MTPA 區被深弱磁值污染（誤差 230 A）。
2. 扭矩標籤 = 實測扭矩: 用命令值會複製舊表的扭矩誤差（驗證 6.9 Nm 原樣保留），
   用實測值可降到 3.1 Nm，且讓多次台架數據可以合併訓練。
3. 物理當約束不當基準: 理論模型的參數不可靠（V_limit 差 2 倍、電感表零凸極），
   殘差模型架構因此移除；只保留不依賴參數的定性約束。

## 5. 禁改事項（踩過的坑）

1. t_cap 必須 cummax 保證單調，改回鄰近窗版本會讓高磁通區被蓋掉（水平點列、鋸齒）。
2. 參考表填補必須差值修正，直接填原值會在邊界產生 100 A 以上斷差。
3. 批次必須夾到樣本數以內（min(batch_size, 樣本數)），否則訓練無效。
4. T=0 列只歸零 Iq，Id 保留弱磁值；全列歸零會使高速空載電壓不可行。
5. applyTableConstraints 內的約束順序不可調換。
6. 勿恢復殘差模型，除非拿到正確的 Lq 表與電壓極限。

## 6. 已知問題

1. Ldq_LUT.xlsx 兩分頁內容完全相同（零凸極），疑提供錯誤，待原廠確認；不影響產表。
2. 完整 V0 報告檔無 T=0 列，T=0 列為模型外插（已驗證合理），台架建議掃高速空載確認。
3. 包絡角點誤差（最大 40-65 A）為單點量測 + 網格解析度極限，解法是補測數據。
4. 溫度未建模；若誤差隨溫度漂移，需在熱穩態重新取數據。
