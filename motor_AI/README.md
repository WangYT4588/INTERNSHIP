# motor_AI - AI 馬達電流查表產生器

用機器學習從台架實驗數據產生馬達控制器的 (扭矩 x 磁通) -> (Id, Iq) 電流查找表，
目標是最小化「扭矩命令 vs 實際扭矩」的誤差。

- 版本: app v1.4
- 環境: MATLAB R2025b + App Designer + Deep Learning Toolbox
- 主程式: `pipeline/app_v1_4.mlapp`

## 快速開始

1. 開啟 `pipeline/app_v1_4.mlapp`，按 Run。
2. 【載入工作資料】按「讀取參考表(Excel)範圍」，選 `data/Idq (Trq, Flux).xlsx`。
3. 同頁按「選擇訓練資料 (CSV)」，選含 TORQUE 實測扭矩欄的完整台架報告檔。
4. 訓練參數: Epochs 2000-3000、LearnRate 0.002-0.0025、Batch 256。
5. 【輸出與 AI 分析】按「執行AI分析」，看報告數字正常後匯出 Excel。

正常結果: Id 誤差平均 3-5 A（最大 40-65 A、集中在高扭矩包絡角點）、Iq 平均約 1 A。

## 三個核心觀念（改程式前必讀）

1. 表軸用 CSV 的 Flux 欄（控制器磁通命令），不是電流反算的物理磁鏈。
2. 扭矩標籤優先用實測扭矩（TORQUE 欄），不是命令值，這樣才能消除扭矩誤差。
3. 產表不依賴電感表與理論模型，物理只以約束形式進入（符號、單調性、限幅、能力包絡）。
